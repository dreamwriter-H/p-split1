# Split Easy v2.0.0 — Google 帳號與單一雲端專案目錄

本版本直接延續 v1.4.0 的聚餐、旅遊及臺灣電子發票功能，重整登入、首頁專案清單與共編權限；不是從零重做 App。

## v2.0.0 核心改版

- 取消匿名登入，使用 Google 帳號作為跨瀏覽器、跨手機都一致的身分。
- 首頁不再把 `localStorage` 當成正式專案目錄，改讀 `users/{uid}/projects` 的雲端成員索引。
- 首頁只列出「我建立的」與「朋友分享」的專案，並清楚顯示角色。
- 同一個專案只有一份正式資料；不同使用者或裝置加入共編時，不會再複製另一個房間。
- 只有專案擁有者能建立邀請連結或永久刪除專案；協作者可離開專案，但不能刪除大家的資料。
- 邀請建立後會顯示完整網址，並提供「複製連結」及手機「系統分享」；自動複製失敗時仍可長按網址。
- Google 彈出登入若被 App 內建瀏覽器關閉，會顯示原因並提供「整頁登入」備用流程。
- 每台裝置第一次開啟 v2 時，會刪除 v1 的本機首頁清單與殘留匿名登入。
- v1 舊邀請連結與舊資料路徑停用，避免清除後被舊分頁重新寫回。

## v2 資料結構

```text
apps/spliteasy-v2/projects/{projectId}
  members/{googleUid}
  invites/{randomInviteId}

users/{googleUid}/projects/{projectId}
```

- `projects` 是唯一正式專案資料。
- `members` 是專案權限名單。
- `invites` 是高強度隨機邀請碼；不能列出，只能讀取網址指定的單筆。
- `users/{uid}/projects` 是個人首頁索引，不保存另一份帳目。

## 完整保留的功能

### 聚餐模式

- 均攤、各自套餐與共享／指定／個人品項混合分攤。
- 每筆品項的「全員」按鈕可反覆切換全選／全不選。
- 百分比或固定服務費、墊付人、整數尾差與結算轉帳。
- 臺灣電子發票整張拍攝、雙 QR 本機辨識及匯入前校對。

### 旅遊模式

- 共同錢包、多人代墊與複雜分攤。
- 第 1 天、第 2 天等日程分頁，可隨時回頭新增或編輯先前天數。
- 每日小計與整趟旅程結算。

## Firebase 上線必要設定

1. Authentication 啟用 Google 登入，並停用 Anonymous。
2. Authorized domains 加入 `dreamwriter-h.github.io`。
3. 部署本版本的 `firestore.rules`。
4. 驗證 Google 登入、建立專案、邀請加入、跨裝置首頁與權限拒絕。
5. 確認 v2 正常後，才清除 v1 舊路徑資料與舊匿名 Auth 使用者。

詳細切換順序見 `MIGRATION_CHECKLIST.md`。

## 隱私與費用

- Google 登入只用來辨認使用者與專案權限，App 不會取得 Google 密碼。
- 發票照片仍只在裝置瀏覽器內解析，不上傳 Firebase。
- 小型親友使用通常可落在 Firebase 免費額度內；仍應在 Firebase Console 設定用量警示並定期查看讀寫量。
