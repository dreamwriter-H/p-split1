## 建議色彩分工

- 品牌主操作：亮藍 #133DD5，白字。新增、儲存、確認、分享遵循同一規則。
- 聚餐識別：橘紅 #FF5B2C；小字用深藍 #16244A，避免白小字對比不足。
- 旅遊記帳：天藍 #86D2FA，深藍字。
- 結算／合計：檸檬黃 #FFE635，深藍字。
- 成員設定／共同錢包：薄荷綠 #8BDCAB，深藍字。
- 全站底色：淺灰白 #F5F4F7；表單與長列表保留白底。
- 刪除／錯誤：紅色另保留，不能因品牌繽紛而變成普通裝飾色。

旅遊分頁建議：設定＝薄荷綠，記帳＝天藍，結算＝檸檬黃；只讓目前選取分頁有明確底色與框線，未選分頁保持淺底。聚餐四步驟仍用橘紅識別，不把每一步改成不同用途色。

## 證據導向發現

1. 品牌銜接：03／04／07／12／15／16／24仍混用青綠、舊藍和深灰主按鈕。先統一主操作與摘要卡，比重排所有頁面更容易維持熟悉感。
2. 旅遊導覽：11／12／13三個分頁目前選取都使用青綠底線。可用分頁功能色搭配文字、底線／框線，不能只靠顏色傳遞狀態。
3. 結算重點：07／08／09深灰摘要卡較重；10／13可用淡黃總額區，保留應收／應付文字與金額，不更動計算。
4. 可讀性：03／06b／13／23多處輔助資訊偏小偏灰。應優先調整必要資訊字級與對比；不把disabled狀態直接當成故障。
5. 危險操作：25永久刪除按鈕與一般確認相同深色。建議紅色明確區隔，保留現有確認步驟；這不等於已加入回收桶。
6. 無障礙界線：截圖不足以證明鍵盤、焦點管理、螢幕閱讀器、真實相機權限全部合格；這些需另做互動檢查。

## 評審與修改順序

A. 先選定色彩規則，尤其旅遊三分頁；B. 統一主按鈕、頁面摘要與用途卡；C. 再處理錢包、收據及共編視窗；D. 對照改前／改後同資料畫面，在320／390px與桌面檢查長姓名、大金額、已選／未選、disabled、錯誤、刪除提示；E. 以同一筆資料核對金額、分攤、付款人不變，再進行使用者確認與部署。
